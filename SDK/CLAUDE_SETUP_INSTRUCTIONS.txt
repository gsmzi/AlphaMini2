CRITICAL API FIX REFERENCE (BehaviorMapper.kt)
================================================================================

WRONG (causes build errors):
- com.ubtrobot.mini.express.ExpressApi.get().express(...)
- com.ubtrobot.mini.action.SquareActionManager.get().playAction(...)
- com.ubtrobot.mini.light.LightApi.get().setBreath(...)

CORRECT (working APIs from SDK):
- com.ubtrobot.express.ExpressApi.get().doExpress(name, loopCount, tweenable, ResourcePolicy, listener)
- com.ubtrobot.action.ActionApi.get().playAction(actionId, ResourcePolicy, ResponseListener)
- com.ubtrobot.action.ActionApi.get().stopAction()
- com.ubtrobot.led.LightApi.getInstance().normalEffect(ledList, ColorUtil.rgbColor(r,g,b), delay, effect)
- com.ubtrobot.led.LightApi.getInstance().breathEffect(ledList, ColorUtil.rgbColor(r,g,b), period, duration, effect)

Reference files for correct API usage:
- ExpressActivity.kt - shows ExpressApi.get().doExpress() usage
- ActionActivity.kt - shows ActionApi.get().playAction() usage
- MainActivity.kt - shows LightApi.getInstance().normalEffect() usage

================================================================================
TROUBLESHOOTING
================================================================================

Problem: Robot doesn't hear/responds randomly
Solution: Check LLM server output - verify Vosk transcription is working

Problem: No audio from robot speaker
Solution: Ensure scrcpy runs with --no-audio flag

Problem: TTS connection failed
Solution: Verify ADB reverse port forwarding is active (adb reverse --list)

Problem: App crashes on audio playback
Solution: Audio files must be in externalCacheDir, not internal storage

Problem: Weather not working
Solution: Uses wttr.in (free, no API key). Check internet connection.

VOICE COMMANDS THE ROBOT UNDERSTANDS
================================================================================

English Commands:
- "dance" - Robot performs a dance
- "wave" - Robot waves
- "hands up" / "raise hands" - Robot raises hands
- "clap" - Robot claps
- "bow" - Robot bows
- "what time is it" - Robot tells the time
- "what's the weather" - Robot tells the weather
- "what's your name" - Robot introduces itself
- "tell me a joke" - Robot tells a joke
- "goodbye" / "bye" / "stop" - End conversation

German Commands:
- "tanz" / "tanzen" - Robot performs a dance
- "wink" / "winke" - Robot waves
- "hande hoch" / "arme hoch" - Robot raises hands
- "klatsch" - Robot claps
- "verbeugen" - Robot bows
- "wie spat ist es" - Robot tells the time
- "wie ist das wetter" - Robot tells the weather
- "wie heisst du" - Robot introduces itself
- "erzahl einen witz" - Robot tells a joke
- "tschuss" / "auf wiedersehen" - End conversation
