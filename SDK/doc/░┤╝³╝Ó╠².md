# 胸口等按键事件监听

## 按键事件监听是通过SysEventApi的事件体系实现的，具体监听方式如下：
    事件采用观察者模式监听，集成KeyEventReceiver实现，包括胸口按键、头部按键、音量键、电源键。不同按键的事件通过不同的Event实现。
    如ChestEvent,HeadEvent,VolumeEvent,它们均继承KeyEvent
```kotlin
        //  创建事件观察者
        val patHeadReceiver = object : KeyEventReceiver() {
            override fun onSingleClick(p0: KeyEvent?): Boolean {
                return handleEvent("single")
            }

            override fun onDoubleClick(p0: KeyEvent?): Boolean {
                return handleEvent("double")
            }

            override fun onLongClick(p0: KeyEvent?): Boolean {
                return handleEvent("long")
            }
        }
        //订阅胸口按键事件
        SysEventApi.get()
            .subscribe(
                ChestEvent.newInstance().setPriority(SysMasterEvent.Priority.LOW)
                    .setEffectNow(true),
                patHeadReceiver
            )
        //取消订阅事件
        SysEventApi.get().unsubscribe(patHeadReceiver)
```
