# PirManager API 文档

## 概述
`PirManager` 是一个管理 PIR（人体红外感应）功能的工具类，主要用于检测有人或物体靠近或离开。它提供了订阅、取消订阅、开启和关闭 PIR 功能的能力。

## 方法列表
### `openPir()`
- **描述**: 开启 PIR 功能，打开传感器数据采集。
- **参数**: 无。
- **返回值**: 无。

### `closePir()`
- **描述**: 关闭 PIR 功能，关闭传感器数据采集并清除所有订阅的监听器。
- **参数**: 无。
- **返回值**: 无。

### `subscribe(listner: (Int) -> Unit)`
- **描述**: 订阅 PIR 事件，当有人或物体靠近或离开时触发回调。
- **参数**:
  - `listner`: 回调函数，接收一个 `Int` 类型的参数，表示 PIR 事件的状态。
- **返回值**: 无。

### `unSubscribe(listner: (Int) -> Unit)`
- **描述**: 取消订阅 PIR 事件。
- **参数**:
  - `listner`: 需要取消的回调函数。
- **返回值**: 无。

### `isPirOpen(): Boolean`
- **描述**: 检查 PIR 功能是否开启。
- **参数**: 无。
- **返回值**: 返回 `true` 表示 PIR 功能已开启，返回 `false` 表示未开启。
